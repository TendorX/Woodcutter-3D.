# Лесоруб 3D (Three.js)

Структура (положите так же в репозиторий, например в папку `lumberjack/`):
- `index.html` — разметка HUD, подключение Three.js (jsDelivr, версия 0.160.0) и Telegram Mini App
- `style.css` — интерфейс, джойстик, панели
- `js/config.js` — весь баланс: цены, скорость топоров, вместимость рюкзаков, стоимость бревна, таймер дерева, задания
- `js/save.js` — сохранение (LocalStorage по Telegram ID). Для Supabase меняется только `provider`
- `js/main.js` — мир, персонаж, рубка, брёвна, конвейер, магазин, инвентарь, задания

Запуск: нужен HTTP-сервер (ES-модули не работают с file://). На GitHub Pages — просто откройте адрес; локально: `npx serve` или `python -m http.server`.
Управление: WASD/стрелки, Shift — бег, E/Пробел — действие, перетаскивание мышью/пальцем — камера, колесо — масштаб. На телефоне — джойстик слева и кнопка справа.
